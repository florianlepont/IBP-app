Both unit configs already set `coverageReporters: ['text', 'text-summary', 'json-summary', 'lcov']` and `coverageDirectory: '<rootDir>/coverage/unit'`, so `--coverage` writes `<workspace>/coverage/unit/coverage-summary.json`: an object keyed by absolute file path plus "total", each value `{ lines, statements, functions, branches }` with `{ total, covered, skipped, pct }`.

Jest coverageThreshold semantics (Jest 29): a key that is a directory path (e.g. "./src/hooks/", resolved against rootDir) is enforced on the AGGREGATE of the files under it; a glob key is enforced PER FILE (do not use globs here); files matched by a path key are removed from "global", and "global" applies to the remaining files. If "global" is set but no files remain, Jest reports an error — so keep at least one file outside the directory keys or omit "global".
