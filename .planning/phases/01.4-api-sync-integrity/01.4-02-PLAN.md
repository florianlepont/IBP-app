What installed apps send (mobile/src/storage/sync.ts, body `JSON.stringify({ operations })`, client_ref = String(queue row id)):
- survey.upsert: payload = the queued SurveyQueuePayload `{ id, sync_version, site_name, status, visibility, parcel_ids (trimmed, upper-cased), region_version, vegetation_stage, factors, scores?, expires_at? }`, possibly with extra keys spread from older local payloads; no survey_id on the envelope
- survey.delete: `survey_id` + payload `{ id }`
- survey.visibility_update: `survey_id` + payload `{ visibility }`
- attachment.create: `survey_id` + payload `{ mime_type, size_bytes, captured_at: null | string, metadata: {} }`
- attachment.delete: `survey_id` + payload `{ attachment_id }`

Parcel ID producers (D-11): synthetic `${communeCode}${section}${number}` = 5 digits + 2 letters + 4 digits (cadastre-provider.service.ts resolveSynthetic); IGN reverse geocoder `normalizeParcelId` keeps any `[0-9A-Z]` characters (cadastre-provider.service.ts), IGN WFS uses the raw `idu` upper-cased (surveys.service.ts ~1124), e.g. `75056000AB0012` and Corsican `2A004000AB0012`; legacy parse regex `^\d{5}[A-Z]{1,3}\d{1,4}$`.
