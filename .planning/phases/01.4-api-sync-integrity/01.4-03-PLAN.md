## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.4-11 | Tampering | upsert TOCTOU on sync_version | mitigate | Row read FOR UPDATE + `AND sync_version < $n` in the UPDATE; zero-row outcome re-checked (idempotent or 409) |
| T-01.4-12 | Tampering | Concurrent submit duplicate version (A-M7) | mitigate | Sorted `SELECT ... FOR UPDATE` on parcels before the version check; residual 23505 → 409 |
| T-01.4-13 | Repudiation | Lost change events (ARCH-3) | mitigate | Row write + event in one transaction; E2E injected failure proves rollback and replay |
| T-01.4-14 | Denial of Service | Deadlocks / pool exhaustion | mitigate | Consistent lock order (survey row, then parcels sorted); every statement in the callback uses the transaction handle |
| T-01.4-15 | Elevation of Privilege | Cross-user survey id on create | mitigate | `ON CONFLICT (id) DO NOTHING` + ownership re-check → 409 survey_id_conflict; every query keeps its user_id predicate |
| T-01.4-16 | Tampering | Silent parcel-linkage loss (A-M1) | mitigate | Error-swallowing catches removed; failures abort the transaction |
