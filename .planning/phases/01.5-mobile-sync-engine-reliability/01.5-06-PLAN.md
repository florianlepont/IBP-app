<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> API download-url | Authenticated request for a signed URL |
| app -> object storage | Bearer-less GET on a presigned URL |
| network bytes -> device file | Downloaded content is written under documentDirectory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.5-18 | Information Disclosure | Bearer token sent to object storage | mitigate | Authorization header only when requires_auth is true (tested both ways) |
| T-01.5-19 | Tampering | Download written outside the attachments dir | mitigate | Destination built only by buildAttachmentFileUri from the server attachment id + a mime-derived extension; no server-supplied path is used |
| T-01.5-20 | Tampering / data loss | Downloads racing a logout purge or an attachment delete | mitigate | Every download runs inside syncActivity.run (purge waits); the post-download UPDATE checks changes and removes the orphan file |
| T-01.5-21 | Denial of Service | Unbounded parallel downloads / hung downloads | mitigate | Max 2 concurrent, per-id de-duplication, 60 s timeout per download |
| T-01.5-22 | Elevation of Privilege | Downloads for another account's local data | mitigate | Gated by syncAllowed (phase 01.2 owner gate, default-deny); server enforces ownership (plan 02) |
</threat_model>
