| Boundary | Description |
|----------|-------------|
| camera / photo library -> app | Arbitrary-size images enter the app |
| app -> upload target | File bytes streamed to the API or a presigned URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.5-23 | Denial of Service | Full-resolution photos in memory / on the wire | mitigate | Resize to <= 2048 px long edge, JPEG 0.7, streamed upload from disk (no blob), 120 s cancellation |
| T-01.5-24 | Information Disclosure | Bearer token sent to a presigned URL | mitigate | Authorization header only for the API upload route (tested both ways) |
| T-01.5-25 | Information Disclosure | Photo EXIF metadata (GPS) uploaded | accept | Re-encoding through the manipulator drops most EXIF; location is already part of the survey data owned by the same user; no new exposure |
| T-01.5-26 | Denial of Service (data loss) | OS purging cached photos of unsynced surveys | mitigate | New photos go to documentDirectory; legacy cache photos are copied at startup and their rows/payloads repointed in one transaction |
</threat_model>
