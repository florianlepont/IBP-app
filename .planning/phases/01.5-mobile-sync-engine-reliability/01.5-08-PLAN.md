<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> client sync results | Per-operation statuses and error codes drive local state |
| server changes feed -> local SQLite | Pulled surveys and attachments are written over local rows |
| network -> client | Slow or hostile networks stall requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.5-27 | Tampering (data loss) | Pull overwriting pending/blocked local edits | mitigate | Guard on any queue row OR sync_blocked for updates and deletions; real-SQL tests for both |
| T-01.5-28 | Denial of Service | Endless retry of an ambiguous failure / silent never-blocked rows | mitigate | Counted failures cap at 8 then sync_blocked with a visible code; tested |
| T-01.5-29 | Denial of Service (data loss) | Transient outages consuming the cap and blocking good data | mitigate | Network, timeout, 5xx, 429 classified retryable and never counted; 20-attempt tests per class |
| T-01.5-30 | Denial of Service | Hung requests freezing sync | mitigate | apiRequest timeout on every JSON call including the body read; 60 s batch timeout |
| T-01.5-31 | Spoofing | Expired token treated as a data failure | mitigate | Batch 401/403 rethrown untouched so withAuthRetry refreshes; rows unchanged (tested) |
