## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent UI triggers -> sync engine | Autosave, reconnect, manual sync, visibility toggle and attachment delete can fire together |
| client -> POST /sync | Batches cross the network; the server rejects batches over 100 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.5-35 | Tampering | Duplicate drains replaying the same rows | mitigate | Module-level single flight at the exported entry points; test asserts one POST for two triggers |
| T-01.5-36 | Denial of Service | Oversized batch rejected by the server (1..100 bound, phase 01.4) | mitigate | SYNC_BATCH_SIZE = 100 chunks; 250-op test asserts 100/100/50 |
| T-01.5-37 | Repudiation (false "synced") | Survey shown synced with work still queued | mitigate | NOT EXISTS guard in the same transaction as the row delete; cross-batch and mixed-result tests |
| T-01.5-38 | Tampering | Interleaved writes between a pull and a drain | mitigate | Cross-kind serialisation in the flight plus per-page transactions with the cursor |
| T-01.5-39 | Denial of Service | Deadlock from nested transactions | mitigate | Helpers take tx; runInTransaction never called inside a callback; no transaction spans network I/O |
