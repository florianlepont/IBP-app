## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client-chosen ids → storage keys | Survey ids come from clients and end up in file paths / object keys |
| Client-declared MIME → allow-list | MIME strings are client input |
| API → object store | Presigned URLs hand upload rights to clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.6-04 | Tampering | Local-mode path traversal via ids | mitigate | isSafeId on every key segment in the builders plus resolveLocalPath containment (resolve + root + sep prefix) on every keyed call |
| T-01.6-05 | Tampering | isAllowedMimeType prototype lookup | mitigate | Object.prototype.hasOwnProperty.call on the allow-list in both helpers; spec covers constructor/__proto__/toString |
| T-01.6-06 | Denial of Service | Oversized presigned uploads | mitigate | presignPut signs ContentLength = declared size; confirm-time size compare added by plan 07 |
| T-01.6-07 | Information Disclosure | Missing object handling | mitigate | getObject/headObject return null on not-found, other errors propagate and are not echoed |
</threat_model>
