Current getSyncChanges (api/src/surveys/surveys-sync.service.ts ~192-341): return type `{ cursor_in: string | null; cursor_out: string | null; has_more: boolean; events; surveys; attachments }`. Events query on `(created_at, id)` at ~204-250; when events exist it loads surveys/attachments (`loadSyncChangeSurveys`, `loadSyncChangeAttachmentsByIds`, keep both) and returns `cursor_out = buildChangesCursor(lastEvent.created_at, lastEvent.id)`. The fallback at ~252-340 (plus `loadSyncChangeSurveysWithoutEvents` ~440-486 and `loadSyncChangeAttachmentsBySurveyIds` ~413-438, used only by the fallback) is to be deleted. The empty-result return today uses `cursor_out: parsedCursor.original`.

New events query (PATTERNS C-1, verified on PG 16): `SELECT e.id, e.survey_id, e.actor_id, e.event_type, e.payload, e.created_at::text, e.xid8::text AS xid8, e.seq::text AS seq FROM survey_events e JOIN surveys s ON s.id = e.survey_id WHERE s.user_id = $1 AND (e.xid8, e.seq) > ($2::xid8, $3::bigint) AND e.xid8 < pg_snapshot_xmin(pg_current_snapshot()) ORDER BY e.xid8 ASC, e.seq ASC LIMIT $4` with `[user.id, xid8, seq, limit + 1]`; start position for "none" is ("0", "0").
Legacy translation (PATTERNS C-6): `SELECT e.xid8::text AS xid8, e.seq::text AS seq FROM survey_events e JOIN surveys s ON s.id = e.survey_id WHERE s.user_id = $1 AND (e.created_at, e.id) <= ($2::timestamptz, $3) ORDER BY e.xid8 DESC, e.seq DESC LIMIT 1`; no row → ("0", "0").
cursor_out rules: events returned → v2 of the last returned event; no events and kind none → null; no events and kind position → the incoming cursor; no events and kind legacy → the translated v2 cursor (mobile persists cursor_out only when it differs, mobile/src/storage/sync.ts:1141-1152).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.6-08 | Tampering | Cursor values in SQL | mitigate | Parsed by the strict helper, bound as `$n::xid8` / `$n::bigint` / `$n::timestamptz` parameters, never interpolated |
| T-01.6-09 | Information Disclosure | Legacy translation query | mitigate | Translation joins surveys and filters `s.user_id = $1`, so a crafted cursor only positions within the caller's own events |
| T-01.6-10 | Repudiation | Silently skipped events (ARCH-6) | mitigate | Snapshot filter + (xid8, seq) paging; three-case concurrency E2E |
| T-01.6-11 | Denial of Service | Long-running writer holds back xmin | accept | Delay only, never a skip; documented in sync-conflict-resolution-v1.md by plan 08 |
| T-01.6-12 | Denial of Service | Unbounded fallback re-send | mitigate | Fallback deleted; inverted E2E asserts event-less rows are not re-sent |
