<objective>
Turn same-`sync_version` writes with different content into a `sync_version_conflict` instead of a silent replay, by comparing the existing read-only fields by value at the three call sites in `SurveysService`. A difference in visibility alone is not a conflict: it is applied last-writer-wins like the existing `visibility_update` action and answered `synced` (D-16 as amended 2026-09-25), so installed apps that rewrite a pending upsert's visibility keep syncing with no mobile change. In the same file (hotspot, one owner per wave), drop the service's own S3 client and route survey-deletion cleanup through `StorageService`.

Purpose: REQ-AUD-changes-feed (ROADMAP criterion 2, same-version half) and REQ-AUD-object-storage (criterion 3, surveys half). Decisions D-04, D-05, D-16.
Output: comparison helper with unit tests, rewired SurveysService, E2E proof.
This plan runs in parallel with plan 07, which owns surveys-attachments.service.ts; do not edit that file here.
</objective>
