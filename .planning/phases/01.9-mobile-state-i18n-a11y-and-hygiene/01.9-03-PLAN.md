Script contract (CommonJS, no dependency beyond `typescript`, which is installed; place it in `mobile/scripts/` so it is outside the coverage glob `src/**`):
- `findUnusedStyleKeys(files: string[]): Array<{ file: string; key: string }>`: for every `StyleSheet.create({...})` object literal (including `export const styles = StyleSheet.create`), a key is used when some file that is the defining file or imports it reads `<binding>.<key>` or `<binding>["key"]`; a style object indexed with a non-literal (`styles[tone]`) marks every key of that object as used (dynamic use).
- `findLongFiles(files: string[], maxLines = 400): Array<{ file: string; lines: number }>` for files under `src/screens/` and `src/navigation/` (every `.ts`/`.tsx`, `.styles.ts` included; `*.test.*` excluded).
- `findUserFacingLiterals(files: string[]): Array<{ file: string; line: number; kind: string; text: string }>`: outside `src/i18n/`, flags JSX text containing a letter, string or template literals in JSX props `title|label|placeholder|accessibilityLabel|accessibilityHint|subtitle|message|description|emptyText`, first two arguments of `Alert.alert` and `text` of its buttons, and string/template literals passed as the first argument of `setStatus`, `onStatusChange`, `reportStatus` (third argument for the 3-argument form). Ignore tests, `console.*` arguments, `new Error(...)` (technical, never displayed once status uses the catalogue) and non-letter strings.
- `findStatusIdLeaks(files: string[]): Array<{ file: string; line: number; text: string }>`: calls to `setStatus`/`onStatusChange`/`reportStatus` whose argument expression contains an identifier or property named `id`, ending in `Id`/`_id`, or a `.message` property access (raw error text).
- CLI: `node mobile/scripts/structure-report.js <unused-styles|long-files|literals|status-ids> [paths...] [--max N] [--json]`. Paths are relative to `mobile/` (files or directories, default `src`); prints `<check>: <count>` then one line per item; exit 1 only when `--max N` is given and count > N.
- Mobile tests may `require` (the mobile override disables no-require-imports for tests). Type the required module with a local `type StructureReport = { … }` cast.
