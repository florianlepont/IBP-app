`nyquist_compliant: true` because every task of all 32 plans has an `<automated>` command, including the orchestrator-evidence checkpoints, which grep the recorded evidence. ## Sampling Rate

- **Model identifiers and attribution:** none in code, this file or PR body drafts. Commit trailers are the orchestrator's concern, not copied anywhere else
- **After every task commit:** run the task's `<automated>` command (targeted suite, per-folder scanner and ESLint gates)
- **After every plan:** full mobile unit suite with coverage, lint, typecheck and format. Plans touching the API also run the full E2E suite on their own database
