# Mobile (Expo + React Native)

## Stack
- React Native
- Expo
- TypeScript

## Environment
Create `mobile/.env` from `.env.example`:

```bash
cp mobile/.env.example mobile/.env
```

Default value:
- `EXPO_PUBLIC_API_URL=http://localhost:3000/v1`

## Run
```bash
npm run dev:mobile
```

Then open the app and tap **Check API /health**.
